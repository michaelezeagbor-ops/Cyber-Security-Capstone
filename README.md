Title: Combating Social Engineering in Online Gaming Communities:
A Framework-Based Cybersecurity Awareness Strategy

Description: The underexamined threat against gamers that is social engineering is critically examined in this capstone project. By using a cybersecurity awareness strategy, that instead of being focused on more formal, organizational settings, and instead is adapted to the more informal gaming community, scamming campaigns, impersonations, malicious mods, and other dangers presenting through social engineering can be minimized through the incorporation of more established frameworks in cybersecurity such as NIST CSF, the SANS Security Aware Maturity Model, and the NICE framework. By improving gamer security habits, social engineers can be become a far less effective threat through an improved cybersecurity hygiene that acknowledges the gaming ecosystem, and the behavioral forces at play.
Tools and Technologies Used

Cybersecurity Frameworks: NIST Cybersecurity Framework (CSF), SANS Security Awareness Maturity Model, NICE Framework
Threat Intelligence Sources: Kaspersky Labs, LastPass, Norton, Verizon DBIR
Platforms Analyzed: Steam, PlayStation, Xbox, Epic Games, Riot, Discord
Analytical Methods: Literature review, attacker behavior analysis, user behavior modeling
Technical Concepts: MFA, account protection practices, phishing pattern recognition, malicious mod analysis
